42 · System Administration

Inception

A small infrastructure of Docker containers, each one built from Debian, wired together by Docker Compose and reached through a single TLS entrypoint.

Services

  • WordPressWebsite served by php-fpm
  • WordPress adminAdministration panel
  • AdminerDatabase management for MariaDB
  • RedisObject cache for WordPress

How a request travels

  1. The browser opens https:// on port 443.
  2. NGINX terminates TLS (v1.2 / v1.3 only).
  3. PHP pages go to php-fpm over FastCGI; this page comes from its own container.
  4. WordPress reads MariaDB and caches objects in Redis.
